Transfert d’argent

Envoyez de l’argent en Guinée et dans la sous-région.

Depuis *440#, transférez vers un proche, un client ou un partenaire. Le transfert national permet d’envoyer de l’argent partout en Guinée, vers un abonné MoMo comme vers un non-abonné : frais de 1 000 GNF, de 2 000 GNF à 15 000 000 GNF. Le transfert international permet d’envoyer vers plusieurs pays avec des frais de 1%.

Retrait sans carte · GAB UBA

Retirez votre cash sur un distributeur UBA, sans carte.

1. Sur votre téléphone

  1. Ayez un compte MoMo actif.
  2. Composez *440*8*3# et choisissez l’option 1.
  3. Générez un code de retrait.
  4. Entrez votre code secret pour valider.
  5. Choisissez et confirmez un code à 4 chiffres.
  6. Entrez un montant entre 50 000 et 800 000 GNF.

2. Devant le guichet UBA

  1. Rendez-vous à un distributeur (GAB) UBA.
  2. Appuyez sur une touche, choisissez la langue puis Mobile Money.
  3. Entrez le code temporaire à 4 chiffres.
  4. Entrez le code généré à 6 chiffres.
  5. Entrez le montant et validez : récupérez votre cash.

Composez *440#, choisissez transfert d’argent puis suivez les instructions.

Rendez-vous chez un agent agréé, confirmez l’opération et récupérez votre argent.

Comment payer une facture ?

Utilisez le menu *440*4# puis sélectionnez EDG, TV ou le service public concerné.

La liaison se fait en agence, chez nos banques partenaires.

Où trouver un agent ?

Contactez l’assistance Areeba ou rendez-vous dans une agence, boutique ou point agréé. Composez *111# option 4 ou 5 pour trouver l’agence la plus proche de vous.
