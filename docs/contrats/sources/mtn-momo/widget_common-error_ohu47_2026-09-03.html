Common Error Codes

The complete definitions of error codes are found in the swagger documentation. Below is the list of error codes available.

Les definitions completes des codes d'erreur sont disponibles dans la documentation Swagger. Ci-dessous se trouve la liste des codes d'erreur disponibles.

Common Error Codes

HTTP Code Error Response Code Description Action
409 RESOURCE_ALREADY_EXIST Duplicated Reference ID. Every request must have a unique reference ID; using an ID of the previous request will result in this error response. ID de reference duplique. Chaque requete doit avoir un ID unique ; l'utilisation d'un ID deja utilise entrainera cette erreur. Check X-Reference ID used is unique and is in UUID V4 format Verifiez que le X-Reference ID utilise est unique et au format UUID V4.

404 RESOURCE NOT FOUND Reference ID not found. Requested resource does not exist. Predominantly occurs with Get Status API and implies that the requested reference ID does not exist. This results in the Request to Debit or Transfer transaction being unsuccessful. ID de reference introuvable. La ressource demandee n'existe pas. Cela se produit principalement avec l'API Get Status et signifie que l'ID n'existe pas. Cela entraine l'echec de la transaction Request to Debit ou Transfer. Check if the original request to pay or the transfer (disbursement) operation was successful with response code 202. Verifiez si la requete initiale (request to pay ou transfer) a ete acceptee avec le code 202.
400 REQUEST REJECTED/ BAD REQUEST Bad request. Request does not follow the specification. Mauvaise requete. La requete ne respecte pas les specifications. This relates to any of the below scenarios:
- Incorrect/wrong values in the headers, and/or the X-ref ID does not meet UUID Version 4.
- Inputting a Body in an API that is not supported e.g. /Token API
- Having unsupported special characters in the Body request for example an apostrophe (').
- Invalid currency - needs to match the target environment currency.
- More than 160 characters in the note and message; explore utilizing the notification API for increased number of characters.
- The URL posted to needs to reviewed e.g. incorrect number of forward slashes (///).		 Cela peut etre du aux cas suivants :
- Valeurs incorrectes dans les headers ou X-ref ID non conforme au format UUID V4
- Presence d'un Body dans une API qui ne le supporte pas (ex : /Token API)
- Presence de caracteres speciaux non supportes dans le Body (ex : apostrophe ')
- Devise invalide ne correspondant pas a l'environnement cible
- Plus de 160 caracteres dans note ou message (utiliser Notification API si necessaire)
- URL incorrecte (ex : nombre incorrect de "/")
403 FORBIDDEN IP Authorization failed. IP not authorized to utilize Disbursement API. Echec d'autorisation. IP non autorisee a utiliser l'API Disbursement. Share your originating Public IP from which the APIs are called with your MTN Account Manager. Partagez votre IP publique avec votre Account Manager MTN.
500 NOT_ALLOWED Authorization failed. User does not have permission.The account authenticated with the Request via Token is restricted. Echec d'autorisation. L'utilisateur n'a pas les permissions necessaires. Le compte authentifie est restreint. Contact your MTN Account Manager. Contactez votre Account Manager MTN.

Common Error Responses with Action

Type Description Action
INTERNAL_PROCESSING_ERROR Default or Generic error code used when there is no specific error mapping. This predominantly occurs due to insufficient customer funds to complete the transaction.
Also related to service denied or Wallet Platform is not reachable. 		Code d'erreur generique utilise lorsqu'aucune correspondance specifique n'existe.
Cela se produit principalement en cas de fonds insuffisants ou si la plateforme Wallet est indisponible.		 Advice customer to ensure they have sufficient funds to complete the transaction. Also request the customer to retry the transaction. If the problem still occurs with sufficient customer funds, please contact your MTN Account Manager for further investigation. Demandez au client de verifier ses fonds et de reessayer. Si le probleme persiste, contactez le Account Manager MTN.
PAYEE_NOT_FOUND The MSISDN being paid to is invalid. Le MSISDN du beneficiaire est invalide. MSISDN format must include country code. MSISDN is not registered for Mobile Money Service. Le MSISDN doit inclure le code pays et etre enregistre pour le service Mobile Money.
PAYER_NOT_FOUND MSISDN of the number from whom the money was requested in invalid. Le MSISDN du payeur est invalide. MSISDN format must include country code.MSISDN is not registered for Mobile Money Service. Le MSISDN doit inclure le code pays et etre enregistre pour le service Mobile Money.
COULD_NOT_PERFORM_TRANSACTION This can be attributed to transaction timeout. This predominantly occurs with a delay to approve a transaction within the given time frame (5 minutes). Echec de transaction, generalement du a un timeout (delai de validation depasse, 5 minutes). Advise customer to try again and approve transaction within 5 minutes. Demandez au client de reessayer et de valider la transaction dans les 5 minutes.
